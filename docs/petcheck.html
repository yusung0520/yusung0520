팀 프로젝트

PetCheck

사료 라벨에서 읽은 성분을 반려동물별 회피 성분 목록과 비교합니다.

담당
RAG 연동, 회피 성분 매칭, 분석 응답 설계
사용 기술
Spring Boot / FastAPI / PostgreSQL

시작한 이유

같은 성분도 제조사에 따라 표기가 달라질 수 있습니다. 이미지에서 추출한 텍스트를 확인하고 고친 뒤, 검색 결과를 반려동물별 회피 성분과 대조하는 흐름을 백엔드에 연결했습니다.

분석 결과를 화면에 어떤 형태로 전달할까?

분석 결과가 JSON 문자열로 전달되면 프론트에서 한 번 더 해석해야 했습니다. 상세 응답에 성분별 판정과 일치 개수를 담는 객체를 두어, 화면이 필요한 항목을 바로 읽을 수 있게 했습니다.

분석 결과를 조회할 때 이전 형식으로 저장된 RAG 응답도 현재 응답 형태로 변환합니다. 일치, 불일치, 판단 불가를 구분해 검색 결과가 불확실한 경우를 표현합니다.
